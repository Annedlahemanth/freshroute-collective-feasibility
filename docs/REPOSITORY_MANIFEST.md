# Repository Manifest

## Primary artefact

`artefact/FreshRoute_Final_Decision_Artefact.xlsx`

The complete decision-support workbook used for the Route 3 project.

## Research evidence

`research/FreshRoute_Research_Log.xlsx`

Research audit trail covering search/source routes, retained evidence, limitations and decision use.

## Browser-readable evidence

The `evidence/` directory contains CSV exports of key evidence and audit tables so that the supporting logic can be inspected without opening Excel.

## Interactive showcase

`docs/index.html`

Self-contained interactive scenario model. It can also be served through GitHub Pages.

- `posters/FreshRoute_Decision_Model.pdf`

The assessed business-plan report and ethics documentation are submitted through Coventry University's assessment process and are not duplicated here.
