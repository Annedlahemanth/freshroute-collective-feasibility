Business model

FreshRoute is a supplier-neutral coordination layer. SMEs continue to order from and pay their suppliers directly. FreshRoute coordinates compatible chilled orders; a contracted refrigerated 3PL carries custody during collection and delivery.

FreshRoute coordination layer
cut-off + eligibility • route data • custody records • temperature evidence • exceptions • weekly review
Local / specialist suppliersPrepare labelled, route-ready orders.
→
Contracted refrigerated 3PLCollects, maintains chilled custody and delivers.
→
Independent food SMEsReceive chilled delivery; retain supplier choice.

Pilot boundary: FreshRoute does not buy speculative stock, own a fleet or operate a permanent warehouse.

Stage-gated implementation

G0 - Validate architecture
Actual 3PL quote; FBO/registration; custody; insurance; route zone.
G1 - Build cluster
Qualify independence, supplier pattern, chilled flows, weights, windows and price acceptance.
G2 - Configure controls
Contracts, SOPs, temperature/custody records, product eligibility and exception rules.
G3 - Controlled pilot
Capture real times, loads, temperature, OTIF and route cost.
G4 - Evaluate
Replace scenario inputs with actual operating data; target ≥10% EBITDA margin.
G5 - Scale
Scale only after stable compliance, service, retention and operating headroom.
